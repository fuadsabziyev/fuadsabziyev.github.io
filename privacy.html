Privacy Policy

FOK Uploader · Effective date: 3 November 2026

FOK Uploader ("the app") is a private tool operated by the owner of the FOK YouTube channel. It uses YouTube API Services. By using the app you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data the app accesses

  • An OAuth access token for the channel owner's Google account, granted with the YouTube upload and YouTube management scopes.
  • The channel's own playlists and the videos the app uploads.

How the data is used

The data is used only to upload FOK's own videos to the FOK channel, set their metadata and add them to the channel's playlists. Nothing else is read or changed.

Storage and sharing

The OAuth token is stored only on the channel owner's own computer. No data is sent to any server other than Google/YouTube, sold or shared with third parties. The app does not use cookies and does not collect data about viewers.

Revoking access

Access can be revoked at any time at Google security settings. Deleting the token file on the computer removes all stored data.
